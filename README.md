# Сжатие строк с использованием собственных динамических структур данных
**Язык программирования:** C++

## 🎯 Цель проекта
Разработка программы для сжатия строки, состоящей из символов латинского алфавита. Программа выполняет замену подряд идущих одинаковых символов на символ и количество его повторений, поддерживает ввод данных разными способами, проверку корректности данных и сохранение результата в файл.

## 📦 Описание
Программа представляет собой консольное приложение на C++, которое выполняет сжатие строк по правилу повторяющихся символов.
Например:
aaabbb -> a3b3 -> (остается без изменений)
aaaabbaaacccaaa -> a4b2a3c3a3 -> (остается без изменений)

Для хранения групп одинаковых символов используется собственный односвязный список. Это позволяет не использовать готовые контейнеры для основной структуры данных и соответствует требованиям проекта.

### ✅ Функционал
* **Сжатие строки с клавиатуры** — пользователь вводит строку, программа проверяет ее и выводит результат сжатия.
* **Сжатие строки из файла** — программа считывает строку из текстового файла, проверяет ее и выполняет сжатие.
* **Случайная генерация строки** — пользователь задает длину строки и количество используемых букв алфавита.
* **Показ последнего результата** — программа выводит последний полученный результат сжатия.
* **Сохранение результата** — результат сжатия можно сохранить в текстовый файл.
* **Встроенные тесты** - программа содержит набор тестов для проверки основных функций.
* **Обработка ошибок** - программа корректно реагирует на неверный ввод, ошибки файлов и отсутствие результата для сохранения.

## 🧩 Используемые технологии
* `iostream` — ввод/вывод данных через консоль.
* `string` — работа со строковыми данными.
* `fstream` — чтение и запись файлов базы данных.
* `filesystem` — проверка пути при сохранении результата.
* `random` — генерация случайной строки.
* `stdexcept` — создание и обработка собственных исключений.

## 🖥️ Инструкция по запуску

  ### Шаг 1. Скачивание проекта
  Скачайте архив с исходным кодом проекта или склонируйте репозиторий.

  ### Шаг 2. Компиляция программы
  Откройте терминал в папке с проектом и выполните команду:

  g++ -std=c++17 -Wall -Wextra -Wpedantic *.cpp -o ikm
  
  ### Шаг 3. Запуск программы

  Для `macOS/Linux`:

  ./ikm

  Для `Windows` после компиляции:

  ikm.exe

  ### Шаг 4. Использование программы
  После запуска появится консольное меню. Выберите нужный пункт, вводя соответствующую цифру и нажимая Enter.

## 🔢 Интерфейс программы
Главное меню приложения:

  1. Сжать строку с клавиатуры — ввод строки вручную и вывод результата сжатия.
  2. Сжать строку из файла — чтение строки из текстового файла и сжатие.
  3. Сжать случайную строку — генерация строки по заданным параметрам и сжатие.
  4. Показать последний результат — повторный вывод последнего результата.
  5. Сохранить последний результат в файл — запись результата в текстовый файл.
  6. Запустить тесты — выполнение встроенных тестов программы.
  0. Выход — завершение работы программы.

## 💾 Формат файла для сохранения результата
Результат сохраняется в текстовый файл в следующем формате:

исходная строка -> сжатая строка -> (остается без изменений)

Пример:

`aaabbb -> a3b3 -> (остается без изменений)`

## 💾 Формат файла для загрузки

Данные загружаются с текстового файла в следующем формате:

исходная строка

## 💡 Особенности и ограничения
  1. Принимаются только латинские буквы, пустая строка не допускается.
  2. Цифры, пробелы, русские буквы и знаки препинания запрещены.
  3. Данные можно ввести с клавиатуры, из файла или сгенерировать случайно.
  4. Длина случайной строки: от 1 до 1000.
  5. Количество букв для генерации: от 1 до 26.
  6. Для хранения групп символов используется собственный список RunList.
  7. Результат можно сохранить в текстовый файл.
  8. При ошибках программа выводит сообщение и продолжает работу.
